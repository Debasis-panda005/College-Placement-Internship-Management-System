# 🎓 College Placement and Internship Management System

A web-based application designed to simplify and manage the college placement process, internship opportunities, student applications, interview scheduling, and selection tracking through a centralized platform.

The system provides role-based access for students, placement coordinators, and administrators, helping streamline placement activities and improve transparency throughout the recruitment process.

---

## 📌 Project Overview

The **College Placement and Internship Management System** is an Advanced Java project developed to digitize campus recruitment activities.

The platform enables placement coordinators to publish job and internship opportunities, manage student applications, shortlist candidates, schedule interviews, and track final selection outcomes.

Students can register, securely log in, explore opportunities, check eligibility requirements, apply for positions, and track their application progress.

Administrators and authorized coordinators can access a centralized dashboard to monitor important placement statistics and manage recruitment activities.

### 🎯 Project Objectives

* Centralize college placement and internship activities.
* Simplify student registration and authentication.
* Manage job postings and internship opportunities efficiently.
* Automate eligibility checks for student applications.
* Track application statuses throughout recruitment.
* Organize interview scheduling and candidate selection.
* Provide role-based access control for secure management.
* Display key placement statistics through an administrative dashboard.

---

## ✨ Key Features

### 1. 💼 Job and Internship Management

* Create, view, update, and delete job postings.
* Manage full-time, part-time, and internship opportunities.
* Store company names, locations, descriptions, and compensation details.
* Specify internship duration and stipend.
* Define application deadlines and minimum CGPA requirements.
* Configure eligible academic departments.
* Search and filter opportunities by relevant criteria.
* Manage opportunity statuses.

### 2. 👨‍🎓 Student Registration

* Register new student accounts.
* Validate student registration information.
* Validate password length on both the client and server.
* Require passwords to contain at least eight characters.
* Store student information, including academic details.
* Support student profile information such as department, CGPA, graduation year, phone number, skills, and resume URL.

### 3. 🔐 Authentication and Session Management

* Student login and logout.
* Password hashing and verification using the existing password-hashing service.
* Session-based authentication.
* Protected application routes.
* Role-based authorization.
* CSRF protection for supported state-changing requests.

### 4. 📝 Job and Internship Applications

* Submit applications for available opportunities.
* Associate applications with authenticated student accounts.
* Validate application eligibility.
* Track application statuses.
* Review and filter applications.
* Shortlist
